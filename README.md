## 📃 B-Card
PRUEBA TÉCNICA UI/UX FRONT Y MÓVIL

Este repositorio tiene el proposito de implementar una solucion a un usuario simulando la necesidad de compartir sus datos en eventos grandes y tener contactos con otros miembros.

## ⚙️ Tecnologias

En este desarrollo se implemento dos tecnologías presentes, como es React, TypeScript y TailwindV4.

## 🧞 Comandos

Se mostraran todos los comandos necesarios para poder ejecutar la pagina web:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Instalas todas las dependencias.                          |
| `npm run dev`             | Empiezas hostear de forma local el sitio web.      |
| `npm run build`           | Construir el producto en caso de quererlo usar en un ambiente real.        |
| `npm run preview`         | Visualizas la version de produccion antes de ser lanzada.    |
